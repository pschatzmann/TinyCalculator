Detailed Description

template<typename T = float, size_t Capacity = 64>
class TinyCalc::Expression< T, Capacity >

A compiled formula: a fixed-capacity RPN (postfix) program.

Produced by Calculator::compile() and run by Calculator::run(). The storage is inside the object, so no heap allocation is needed.

Template Parameters
Tnumber type
Capacitymaximum number of instructions
