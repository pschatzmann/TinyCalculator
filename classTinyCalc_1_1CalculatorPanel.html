Detailed Description

template<typename RGB_T = tinymd::TINYMD_DEFAULT_RGB_T>
class TinyCalc::CalculatorPanel< RGB_T >

Container for the calculator's widgets. Gestures go to the widget under the touch first. A swipe that no widget handles reaches this container, which reports left swipes through onSwipeLeft.
