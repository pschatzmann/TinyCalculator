Calculator GUI (optional)

TinyCalculatorGui.h provides a calculator keypad built on TinyMaterialDesign. It is not included by TinyCalculator.h, so the core library has no GUI dependency. Include it explicitly:

#include <TinyCalculatorGui.h>
App<RGB565> app(DefaultBoard);
CalculatorGui<RGB565, float> gui(Bounds(0, 0, 240, 320)); // or <RGB565, double>
void setup() { app.begin(); gui.attach(app.screen()); }
void loop() { app.update(); }

It needs TinyMaterialDesign (and therefore TinyGPU) on the include path.

Keypad

The keypad has four pages. The top-left key shows the current page name (Basic, Trig, Math, Special) and switches to the next page.

Page Keys

Every function and constant of the library has a key.

Plotting

x enters the variable x. Plot samples the current expression as a function of x and shows it in a chart with the formula as title. The range of x is given by the From and To fields (default -10 and 10). Points where the expression is undefined (for example sqrt(x) for negative x) are left as gaps.

On the plot screen:

  • Tap From or To, or use the matching keys, to select a field.
  • The numeric pad types into the selected field: digits, - (at the start) and .. DEL deletes the last character.
  • The chart is redrawn whenever both fields hold a valid range with To above From. An invalid range keeps the last valid plot.
  • Back returns to the keypad. The expression is kept.

The default range can also be set in code with gui.setPlotRange(xMin, xMax).

Behaviour

  • Digits, operators and function keys append to the expression.
  • = evaluates the expression. The result, or the error, is shown in the result line. Nothing is evaluated before =.
  • After =, an operator continues with the result (ans); a digit or function starts a new expression.
  • C clears everything, DEL removes the last character.
  • RAD/DEG toggles the angle unit.
  • gui.calculator() gives access to the underlying Calculator, for variables and the angle unit.
