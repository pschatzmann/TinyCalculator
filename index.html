TinyCalculator

Header-only formula parser and evaluator for Arduino and desktop C++, with all common math functions. The number type is a template parameter: float (default) or double.

#include <TinyCalculator.h>
Calculator<float> calc;
calc.setVariable("x", 2.0f);
auto r = calc.evaluate("sin(pi/6) + x^3"); // r.value == 8.5
if (!r) Serial.println(errorText(r.error));

Installation (Arduino)

  1. Download this repository as a ZIP file, or clone it into your Arduino libraries folder: git clone https://github.com/pschatzmann/TinyCalculator.git
  2. In the Arduino IDE, choose Sketch → Include Library → Add .ZIP Library (for the ZIP file) or restart the IDE after cloning.
  3. Examples are under File → Examples → TinyCalculator.

The optional calculator GUI also needs TinyMaterialDesign and TinyGPU, installed the same way.
