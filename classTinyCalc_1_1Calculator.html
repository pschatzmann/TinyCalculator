Detailed Description

template<typename T = float, size_t MaxOps = 64, size_t MaxVars = 8>
class TinyCalc::Calculator< T, MaxOps, MaxVars >

High-level calculator: variables, angle unit, compile and evaluate.

Holds a table of named variables (plus the built-in variable ans), the angle unit, a scratch program and the user-defined functions. Use evaluate() for a single formula, an assignment ("y = x*3") or a function definition ("f(x) = x^2 + 1"). Use compile() + run() to evaluate one formula repeatedly with different variable values.

Unit conversion: units are constants (km = 1000 m, min = 60 s, ...), so "5 km" is 5000, and "expr to unit" divides by the unit: "5 km to mi".

TinyCalc::Calculator<float> calc;
calc.setVariable("x", 2.0f);
auto r = calc.evaluate("x^2 + sin(pi/2)"); // r.value == 5
if (!r) Serial.println(TinyCalc::errorText(r.error));
