Detailed Description

template<typename T, size_t N, typename Resolver>
class TinyCalc::detail::Compiler< T, N, Resolver >

Parses a formula text and emits the RPN program.

A scanner produces tokens on demand and a recursive descent parser generates the instructions of an Expression directly, so no syntax tree is built. It tracks the maximum stack depth needed by the program.

Grammar, from lowest to highest precedence:

  • expr := term (('+' | '-') term)*
  • term := unary (('*' | '/' | '' | implicit) unary)*
  • unary := ('-' | '+') unary | power
  • power := postfix ('^' unary)? (right associative)
  • postfix := primary '!'*
  • primary := number | constant | variable | func '(' args ')' | '(' expr ')'
