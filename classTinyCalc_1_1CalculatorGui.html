Detailed Description

template<typename RGB_T = tinymd::TINYMD_DEFAULT_RGB_T, typename Number = float>
class TinyCalc::CalculatorGui< RGB_T, Number >

Calculator keypad with an expression line and a result line, and a plot of the expression as a function of x.

The GUI owns a Calculator<Number>, so every key press goes through the same parser and evaluator as the rest of the library. The class is independent of the display: press() drives it directly, which allows testing the key logic without a window.

The keypad has several pages. The top-left key shows the current page name and cycles through the pages:

  • Basic: digits, operators, parentheses, "ans", "pi"
  • Trig: trigonometric, inverse and hyperbolic functions, deg/rad, e, tau, phi
  • Math: roots, exponentials, logarithms, rounding, min/max/sum/avg, gcd/lcm
  • Special: gamma, factorial, erf, erfc, comb, perm and a few operators Every supported function and constant has a key.

Key behaviour:

  • digits, operators and function keys append to the expression
  • "=" evaluates the expression; the result stays in the result line and "ans" holds it for the next calculation (an operator after "=" starts from "ans")
  • "C" clears everything, "DEL" removes the last character
  • "RAD"/"DEG" toggles the angle unit used by the trigonometric functions
  • the expression is evaluated only when "=" is pressed
  • "Plot" plots the expression as a function of x (see plotExpression()); "x" enters the variable x.

Plot screen: the From and To fields hold the x range (default -10 .. 10). Tap a field, or use the From/To keys, to select it; the numeric pad types into the selected field. The plot is redrawn whenever both fields hold a valid range with To above From. "Back" returns to the keypad.
