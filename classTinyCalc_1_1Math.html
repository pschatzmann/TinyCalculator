Detailed Description

template<typename T>
class TinyCalc::Math< T >

Mathematical functions and constants for the number type T.

All functions are static. They are built on the C library primitives in detail::Prim, so the float version uses the single-precision functions. Functions with a restricted domain (sqrt, ln, asin, ...) do not check it here; the evaluator reports Error::Domain before calling them.

Template Parameters
Tnumber type: float or double
